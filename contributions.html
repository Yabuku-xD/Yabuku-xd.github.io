Contributions

Pull requests I’ve sent to other people’s projects. Most began as a bug I hit while using the tool.

hermes-agent

· Nous Research

Nous Research’s open-source agent. You talk to it through Discord, Slack, Telegram, or Feishu instead of a separate app.

  • #6452 Persist Discord /sethome channel to .env /sethome wrote the home channel ID to config.yaml, not .env, so the setting was gone after every restart. I sent the handler through the env persistence code that already existed.
  • #6390 Fetch Feishu cloud document links via API When someone shared a Feishu or Lark doc, Hermes tried to open it in a browser and timed out on anything behind a login. It now reads the document through Feishu’s API.
  • #4049 Prepare for Homebrew packaging Dropped a dependency that broke source builds, bundled runtime assets into the source distribution, and made installed paths follow Homebrew’s layout. The release versioning didn’t change.

openchamber

· OpenChamber

A desktop app around the OpenCode CLI agent, with sessions, settings, tool runs, and more than one model provider.

  • #1079 Add Behavior settings page for global AGENTS.md A new settings page where you write one global AGENTS.md. It saves to disk through GET and PUT endpoints, caps the file at 1 MB, and wins over any project-level copy for every provider and session.
  • #1069 Add concurrency controls for multi-session providers Running several sessions against one provider slowed everything down, and health checks sometimes killed the single OpenCode server mid-task. I gated the health checks, added backoff to the SSE stream, and retried failed calls.
  • #1065 Refresh provider models on OpenCode reload After OpenCode restarted, the model list stayed cached, so new models and changed context windows never appeared. It now re-authenticates after a restart and pulls fresh model data on its own.
  • #1064 Fix skills empty state centering and terminal toolbar overlap The empty skills screen sat off-center because a flex container had no height. On narrow windows the terminal quick-keys also covered the dock buttons. Both are fixed.
  • #1058 Keep settings sidebar open, center content, fix worktree refresh Opening a sub-page like Magic Prompts collapsed the settings sidebar to an icon rail. Now it stays open. I also centered settings on wide screens and fixed worktree state going stale after an auth change.
  • #1056 Add per-agent default thinking variant setting You had to change the reasoning level by hand for each agent, every chat. There’s now a Default Thinking dropdown per agent, styled like the Temperature and Top P controls, that only lists what the chosen model supports.
  • #1000 Improve cold start, bundle size, and streaming performance Took blocking I/O off the preferences load, so first paint comes 50–200 ms sooner. Split startup into priority phases so heavy modules load after paint. Memoized the chat export path to cut re-renders while a reply streams.

glass

· Glass HQ

A browser written in Rust on GPUI, the UI framework behind Zed. It composites pages on the GPU instead of using Chromium’s renderer.

  • #57 Virtualize sidebar tab list and pre-collect tab render data Outside macOS, the sidebar rebuilt every tab’s element tree on every frame. I switched it to GPUI’s uniform_list, so it only draws the tabs you can see. Tab data is now gathered once up front, and the scroll position survives re-renders.
  • #56 Reduce spurious rendering and lock contention Suspended tabs and hidden surfaces were firing FrameReady events that caused layout work for nothing. I filtered those out, split the render mutex so the UI and render threads fight less, and removed an extra Arc clone from the hot path.
  • #55 Fix path isolation and omnibox URL navigation Glass was writing its data into Zed’s folders. The SQLite migrations collided and Zed refused to open its own database. Every path now points at a Glass-only directory. I also fixed how the omnibox routes typed URLs.
