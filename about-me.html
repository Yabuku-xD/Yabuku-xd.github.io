Those are AI programs that write and edit code. When I’m not doing that, I’m probably on Spotify or sending pull requests to other people’s projects.

Software Developer Intern at Jevan · Aug 2026–Present

  • Built a restaurant-operations app in TypeScript, Next.js, and PostgreSQL. It reads Toast and Square order data, read-only, for cost, inventory, and labor workflows.
  • Built a recommendation worker that computes menu embeddings in Cloudflare Containers and processes only dish text that changed. Guest rankings come from cached results, so page requests run no model inference.

What I look for in a full-time role:

  • Software with moving parts. Background jobs, OAuth handshakes, data that has to sync, tools people leave open all day. I like the kind of system you can watch fail and then fix.
  • Hard problems that matter to someone. For better or worse, I pick the difficult version if a user is waiting on it.
  • A team that reviews code honestly and shares what it knows. I learn fastest next to people who explain their reasoning.
